# LEONID — фитнес-клуб

Учебный проект Антона Попова, группа 4628, ГУАП. Лендинг восстановлен по скриншотам лабораторной работы №4 и дорабатывается в лабораторной работе №5.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей не нужна: HTML, CSS и JavaScript, без фреймворков. Форма работает в демонстрационном режиме и не передаёт персональные данные.

## Разделы

Главный экран, информация о клубе, оборудование, преимущества, три абонемента, примеры отзывов и контакты с формой.

## Работа с Git

- `main` — основная версия сайта.
- `feature/photos` — фотографии из рабочей папки `images`.
- `docs/lab5` — описание проекта и выполненных изменений.

Исходная версия восстановлена по отчёту, поскольку оригинальные файлы остались на другом компьютере. Контакты, отзывы и цены — элементы учебного макета.
