# LEONID — фитнес-клуб

Учебный проект Антона Попова, группа 4628, ГУАП. Лендинг фитнес-клуба LEONID для лабораторных работ №4 и №5 по информатике.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей не нужна: HTML, CSS и JavaScript, без фреймворков. Форма работает в демонстрационном режиме и не передаёт персональные данные.

## Разделы

Главный экран, информация о клубе, оборудование, преимущества, три абонемента, примеры отзывов и контакты с формой.

## Работа с Git

- `main` — основная версия сайта.
- `feature/photos` — фотографии из рабочей папки `images`.
- `docs/lab5` — описание проекта и выполненных изменений.

Контакты, отзывы и цены — элементы учебного макета.

## Изменения в лабораторной №5

Добавлены три фотографии из папки `images`, заменены блоки-заглушки, фон главного экрана стал фотографическим. Изменения выполнены ИИ-агентом в ветке `feature/photos`, затем объединены с `main`.

В мобильном меню работают закрытие после выбора раздела и клавиша Escape. Форма проверяет имя и российский телефон; выбор тарифа переносится в форму.

Источники фотографий: `images/SOURCES.md`.
